Notes:
- The OGA mirror pages for all three packs repeat the same attribution
  notice: Credit "Kenney.nl" or "www.kenney.nl", "this is not mandatory."
- Each OGA mirror ships FBX only. Kenney's own site lists glTF among its
  formats, but the download route found on kenney.nl pages points at the
  itch.io All-in-1 bundle, which this hunt was forbidden to use — so no
  glTF variant of these packs was downloaded. See `CATALOG.md` (gaps).
- No Sketchfab, itch.io, paid, or account-gated source was used for any
  installed file. No Quaternius file was downloaded in this hunt.
- No file in this folder is claimed CC0 on the basis of a collection
  listing alone: each pack's CC0 status was confirmed in its own
  `License.txt` inside the downloaded zip and on its own OGA page.

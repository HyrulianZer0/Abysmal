# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in Abysmal, **please do not open a public issue about it.**

Use GitHub's **private vulnerability reporting** instead (Security tab → "Report a vulnerability"). That keeps the details private while it gets fixed. You can also reach the project through the contact info in the README.

## What to Expect

- Reports are read and triaged first by the project's maintainer (Milo, on behalf of director Aethelwarden Solas).
- A fix will be worked on privately, then released. You will be credited in the release notes if you want to be.
- Please give us reasonable time to fix the issue before disclosing it publicly.

## Scope

This policy covers the code and assets in this repository. The game itself is free to play, but it is **not free to copy** — see the README for the project's terms.

================================================================
LIFE TREE — Page Navigation Drafts
Producer/Director: Aethelwarden Solas
Drafted Oct 24, 2026 — ideas only, James decides
================================================================

The problem: the Life Tree is an infinite web, and nodes upgrade
indefinitely. Navigation isn't about finding a node — it's about
deciding which node has a good effect right now. James leans to PAGES
over pinch-and-zoom. Three drafts:

----------------------------------------------------------------
DRAFT 1 — RINGS (pages = depth layers)
----------------------------------------------------------------
Each page is one ring of the web. Page 1 is the center: the 5 founders
(Marla, Tovan, Harlan, Sarella, Pello) + the opening stat buffs.
Deeper rings live on later pages; buying a ring's nodes sprouts the
next ring's page.

- Moving: swipe left/right, or tap page dots at the bottom.
- Node display: icon + name + current level + next effect
  ("+2% attack -> +2.2% attack"). Tap a node to upgrade it.
- Infinite growth: new pages appear at the end as rings unlock.
  A "deepest ring" jump button skips the swiping.
- Best for: the incremental feel — each page is visibly "further out"
  than the last, matching the ring-by-ring growth.
- Watch-out: late game means many pages; the jump button matters.

----------------------------------------------------------------
DRAFT 2 — SCOPES (pages = self / town / world / heavens / hell)
----------------------------------------------------------------
One page per scope of the web, matching how the tree's scope grows
with your journey. Self first, then Town (deed), then World, then
Heavens, then Hell as ascension extends the tree.

- Moving: tabs across the top, one per scope. Locked scopes show as
  greyed tabs with their unlock condition ("Reach the deed").
- Node display: same as Draft 1, grouped by scope.
- Infinite growth: each scope's page grows its own rings downward —
  the page itself scrolls vertically as new rings sprout.
- Best for: the story of the tree. You SEE your soul expanding from
  self to cosmos, and every scope feels like a chapter.
- Watch-out: scopes are few, so each page gets long; needs the
  vertical scroll to stay comfortable.

----------------------------------------------------------------
DRAFT 3 — EFFECTS (pages = what the node DOES)
----------------------------------------------------------------
Pages grouped by effect type: Offense, Defense, Survival, Fortune,
Deep (offline/utility). A node lives on the page of its effect,
whatever ring it came from.

- Moving: tabs across the top, one per effect. A "Best right now"
  strip at the top of each page highlights the node with the
  strongest next upgrade for your current build.
- Node display: icon + name + level + next effect, sorted by
  effect strength on that page.
- Infinite growth: new nodes join their effect page as rings sprout;
  pages never run out, they just grow.
- Best for: the actual decision — "which node has a good effect?"
  is answered directly, because the pages ARE the effects.
- Watch-out: the web's shape (rings, scopes) becomes invisible;
  the tree feels more like a menu than a living thing.

----------------------------------------------------------------
QUICK TAKE
----------------------------------------------------------------
Draft 2 fits the story best (self -> cosmos), Draft 3 answers the
decision fastest (what helps me now?), Draft 1 is the simplest to
build. A hybrid is possible: Scope tabs on top (Draft 2) with an
Effects filter inside each page (Draft 3).
